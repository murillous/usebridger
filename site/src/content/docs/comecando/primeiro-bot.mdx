Você vai subir um bot no WhatsApp que responde `pong` ao `!ping`. Precisa do Node 24 ou mais novo (`node --version`) e de um WhatsApp para parear. Se não quiser usar seu número, vá direto para a [versão web](#sem-o-seu-número-transport-web).

## 1. Instalar

```sh
mkdir meu-bot && cd meu-bot
npm init -y
npm pkg set type=module
npm install @usebridger/core @usebridger/transport-baileys @usebridger/storage-sqlite qrcode-terminal
```

O `type=module` faz o Node tratar os arquivos como ES modules, e o Node 24 roda `.ts` direto, sem etapa de build.

Dos pacotes, o obrigatório é o core e um transport: o core não fala com nenhuma plataforma sozinho. O `storage-sqlite` guarda a sessão do WhatsApp para não parear de novo a cada restart, e o `qrcode-terminal` só desenha o QR no terminal.

## 3. Parear e conversar

```sh
node main.ts
```

No celular: WhatsApp, **Aparelhos conectados**, **Conectar um aparelho**, e leia o QR que aparece no terminal.

Para parear por código, passe o número com DDI e só dígitos:

```sh
node main.ts 5511999999999
```

O terminal mostra `Código de pareamento: ...`. Digite-o em **Aparelhos conectados**, **Conectar com número de telefone**.

Depois de conectado, mande `!ping` para o número do bot, de outro contato. A resposta é `pong`. Nas próximas execuções não há QR: as credenciais ficaram no SQLite (`data/bot.sqlite`).

## O que cada peça faz

| Opção do `createBot` | Em uma frase |
| --- | --- |
| `transport` | Fala com a plataforma: recebe as mensagens e envia as respostas. Aqui, o WhatsApp via Baileys. |
| `storage` | Guarda as credenciais da sessão, os dados dos plugins e os jobs agendados. Sem ele, tudo fica em memória e se perde ao parar. |
| `plugins` | A lista do que o bot faz: comandos, reações a eventos, tarefas. |
| `http` | Um servidor HTTP opcional, dividido por todos os bots do processo. Só é preciso se um plugin ou o transport tiver rotas, como o `transport-web`. |

O `createBot` aceita ainda `logger` (ou `logLevel`) para os logs e `api`, a API do core com login, que só existe com `http` e não é preciso para o bot funcionar. Todas as opções estão em [Bot](/usebridger/pacotes/core/bot/).

## Sem o seu número: transport-web

O `transport-web` é o chat que vive dentro de um sistema web seu (ERP, site). Não há pareamento: o sistema emite um JWT e o navegador conversa com o bot por WebSocket. Serve também para testar sem tocar no WhatsApp.

```sh
npm install @usebridger/transport-web
```
